ผู้จัดการอู่ = ทำได้และอนุมัติได้ทุกอย่าง (ยกเว้นส่งออก/ล้างข้อมูล สงวนให้เจ้าของกิจการ) · ธุรการหน้าร้าน = เปิดบิล รับชำระ นัดหมายลูกค้า — ไม่มีสิทธิอนุมัติ/ยกเลิกเอกสาร · หัวหน้าช่าง = เหมือนช่าง + อนุมัติใบเสนอราคาและอนุมัติซ่อม/ตัดสต๊อก · ช่างซ่อม = ดูใบงานซ่อมและสต๊อก — ไม่เห็นราคาทุน ไม่แตะเงิน · คลังอะไหล่ = จัดการสต๊อกเต็ม + อนุมัติใบรับ/เบิก/นับ/เคลมสินค้า · บัญชีการเงิน = รับ-จ่ายเงิน ดูสรุปการเงิน + อนุมัติใบเสร็จ/ใบกำกับ/วางบิล · แคชเชียร์ = รับชำระอย่างเดียว · หัวหน้าอนุมัติ = อนุมัติเอกสารทุกประเภท ไม่ทำเอกสารเอง · ผู้ตรวจสอบ = เห็นทุกเมนูรวมสรุปการเงิน ทำอะไรไม่ได้ — เลือกชุดแล้วยังติ๊กปรับรายข้อต่อได้
