# จุดที่แก้ใน frontend/ หลังแยกไฟล์จากระบบเดิม

`frontend/` สร้างจาก `legacy/DRIVEGO_TRIAL_v23.html` ด้วย `tools/split-legacy.mjs` (เฟส 1) ตั้งแต่เฟส 2 แก้ได้
แต่ทุกจุดต้องอยู่ในรายการนี้ พร้อมเหตุผลและข้อตัดสินที่อนุญาต และ `node tools/split-legacy.mjs --check`
จะล้มถ้ามีไฟล์ที่ต่างจากระบบเดิมแต่ไม่อยู่ในรายการ (ช่อง "ไฟล์")

| # | ไฟล์ | แก้อะไร | ทำไม |
|---|---|---|---|
| 1 | `frontend/js/00-server-storage.js` | ไฟล์ใหม่ สร้างจาก `server/client/storage.ts` ด้วย `tools/build-client.mjs` ห้ามแก้ตรง ๆ | `window.storage` ที่เก็บข้อมูลไว้บน server (เฟส 2 งาน T6, เอกสารออกแบบหัวข้อ 4.1) |
| 2 | `frontend/index.html` | โหลด `js/00-server-storage.js` ก่อน script อื่นทั้งหมด | ต้องมี `window.storage` ก่อน `STORE.init()` ทำงาน |
| 3 | `frontend/js/03.js` | `STORE.init`: เอา `false&&` ออก เพื่อเปิดโหมด `host` ที่ระบบเดิมเขียนไว้แล้ว | ให้ระบบเดิมเก็บข้อมูลผ่าน `window.storage` แทน IndexedDB, ข้อความในหน้าตั้งค่าเป็นของโหมด `host` (Q6) |
| 4 | `frontend/js/01.js` | เอา `window.PKG_AUTO_TRIAL` ออก | ไฟล์ทดลองเตรียมข้อมูลทดลองเองตอนเจ้าของเข้าระบบครั้งแรก ระบบจริงไม่ทำ (A1) |
| 5 | `frontend/js/03.js` | ข้อมูลว่างไม่เรียก `seedDemo36()` (เริ่มระบบตามปกติแทน), สลับผู้ใช้ด้วย PIN ตรวจ PIN ที่ server (`window.storage.checkSecret`) | A1 และ T7: เบราว์เซอร์ไม่มีรหัสผ่านให้เทียบแล้ว |
| 6 | `frontend/js/04.js` | ตอนเริ่ม Franchise ไม่สร้างบัญชีเดโมเมื่อไม่มีบัญชี, ทุกจุดที่เทียบรหัส/PIN (เข้าระบบ, เปลี่ยนรหัส, สลับผู้ใช้) ถาม server แทน | A1 และ T7 |
| 7 | `frontend/js/05.js` | `dgbLogin` และ `dgbOwnerPass` ตรวจรหัสที่ server | T7 |
| 8 | `frontend/js/06.js` | หน้าเข้าระบบ: ถาม server ก่อนแล้วจึงอ่านข้อมูลร้าน, ออกจากระบบ/ทดสอบบัญชีอื่นปิด session ที่ server, เอาลิงก์ "กลับเข้าโหมดทดลอง…โดยไม่กรอกรหัส" การดูในนามเจ้าของ และช่อง "ทดลองสลับบัญชี" ออก, ไม่แสดงบัญชีทดสอบและรหัสผ่าน, ไม่สร้างร้าน/บัญชีเดโม, เปิดหน้าใหม่ขณะยังอยู่ในระบบเข้าโปรแกรมเลย | T7, A1, A3, Q2 |
