ทำอะไรได้บ้าง

งานซ่อมครบขั้นตอน

ใบเสนอราคา อนุมัติซ่อม ตัดสต็อก ติดตามงานค้างส่งมอบ นัดหมายและนัดตรวจเช็กของลูกค้า

รับเงินและเอกสารภาษี

รับเงินสด โอน บัตร หรือแบ่งจ่าย ได้ใบเสร็จทันที ออกใบกำกับภาษี ใบวางบิล ใบลดหนี้ และหัก ณ ที่จ่าย

สต๊อกอะไหล่

ทะเบียนอะไหล่ ราคาขายหลายระดับ รับสินค้าจากผู้ขาย เบิกใช้ภายใน ตรวจนับ และต้นทุนแบบเข้าก่อนออกก่อน

บัญชีและการเงิน

ลงบัญชีให้เองจากเอกสารทุกใบ งบทดลอง บัญชีแยกประเภท งบการเงิน และรายงานภาษีรายเดือน ส่งให้ผู้ทำบัญชีได้ทันที

พนักงานและสิทธิ์

ทุกคนมีบัญชีของตัวเอง กำหนดได้ว่าใครเห็นหรือทำอะไร จ่ายเงินเดือนพร้อมประกันสังคม และระบบจดว่าใครทำอะไร

ข้อมูลปลอดภัย

ข้อมูลของแต่ละร้านแยกกันที่ฐานข้อมูล รหัสผ่านเก็บแบบเข้ารหัส สำรองข้อมูลให้ทุกวัน

แพ็กเกจ

DriveGoBiz

DriveGoProX

ทุกอย่างของ Biz พร้อมเครื่องมือดูแลลูกค้า เช่น รับคิวจอง และเปิดใบเสนอราคาจากอาการเสียที่ลูกค้าแจ้ง

DriveGoFranchise

สำหรับเครือหลายสาขา สำนักงานใหญ่ดูยอดรวมทุกสาขา ดูแลคลังกลาง และอนุมัติใบขอเบิกของสาขา
