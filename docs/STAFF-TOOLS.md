# เครื่องมือทีมงาน DriveGo (เปิดร้าน ลืมรหัสผ่าน วันหมดอายุ งานทุกคืน การแจ้งเตือน)

สำหรับทีมงาน DriveGo เท่านั้น ร้านค้าใช้ไม่ได้ เครื่องมือทั้งหมดอยู่ใน `tools/shop-admin.mjs` รันด้วยรหัสเจ้าของฐานข้อมูล
(doadmin ของ DigitalOcean) ทุกคำสั่งถูกจดในประวัติ (`licence_log`) พร้อมชื่อคนที่รัน (`--by ชื่อ`)

## วิธีรันบน server ทดสอบ (DigitalOcean)

1. DigitalOcean → Apps → **drivego-test** → ส่วนประกอบ **web** → แท็บ **Console** (เปิด shell ในเครื่องที่รันแอปอยู่)
2. คัดลอกข้อความเชื่อมต่อของ **doadmin**: Databases → drivego-test-db → Connection Details → User: doadmin · Connection string
3. ใน Console พิมพ์ (วางข้อความเชื่อมต่อแทน `...` ภายในเครื่องหมาย `'`) ครั้งเดียวต่อการเปิด Console:
   ```
   export MIGRATE_DATABASE_URL='...'
   ```
   **ห้ามวางข้อความนี้ในแชต อีเมล หรือที่อื่น** (เป็นรหัสที่แก้ข้อมูลได้ทุกร้าน) ปิด Console แล้วค่านี้หายไปเอง
4. รันคำสั่งด้านล่าง ต่อท้ายด้วย `--by ชื่อของคุณ` เสมอ

ในเครื่องตัวเอง (`npm run dev`) ใช้ข้อความ `owner database:` ที่ขึ้นตอนเปิดแทนได้

## เปิดร้านจริง

ร้านใหม่เป็นร้านว่าง (ไม่มีข้อมูลตัวอย่าง) มีบัญชีเจ้าของร้าน และวันทดลองใช้ 60 วัน (`--trial`) หรืออู่นำร่อง 1 ปี (`--pilot`)

```
node tools/shop-admin.mjs new รหัสร้าน --biz --pilot --name "ชื่อร้าน" --owner "ชื่อ นามสกุลเจ้าของ" \
  --tax-id 0105545001234 --addr "ที่อยู่" --zip 52000 --tel 0812345678 --email owner@example.com \
  --contact "คุณ... 081-..." --by ชื่อของคุณ
```

- **รหัสร้าน** คือที่อยู่ของร้าน `https://<โดเมน>/รหัสร้าน/` ใช้ตัวพิมพ์เล็ก ตัวเลข และขีด 3–32 ตัว เช่น `daeng-garage` เปลี่ยนทีหลังไม่ได้
- แพ็กเกจ: `--biz` `--prox` หรือ `--franchise` (เครือแฟรนไชส์: ได้บัญชี HQ ชื่อ `hq` ยังไม่มีสาขา HQ เพิ่มสาขาเองในโปรแกรม)
- `--name` และ `--owner` ต้องมี ที่เหลือใส่เท่าที่มี (Biz/ProX: ข้อมูลเหล่านี้จะไปอยู่ในเมนู 10 ตั้งค่าองค์กรตอนเจ้าของเข้าครั้งแรก)
- ชื่อผู้ใช้ของเจ้าของ = รหัสร้านที่ตัดขีดออก (เช่น `daenggarage`) เปลี่ยนได้ด้วย `--user` เจ้าของเข้าด้วยอีเมลก็ได้
- `--from 2026-11-01` เริ่มนับวันจากวันอื่น (ค่าตั้งต้นคือวันนี้)
- เครื่องมือแสดง**รหัสผ่านชั่วคราวครั้งเดียว** บอกเจ้าของร้านทางโทรศัพท์ แล้วให้เปลี่ยนเองหลังเข้าระบบ
  (Biz/ProX: ปุ่ม 🔑 ในแถบเจ้าของร้าน · Franchise: ปุ่มเปลี่ยนรหัสผ่านของบัญชี) **ไม่ส่งรหัสทางแชตหรืออีเมล ไม่จดไว้**

## เจ้าของร้านลืมรหัสผ่าน

ก่อนให้รหัสใหม่ **ต้องยืนยันว่าเป็นเจ้าของร้านจริง**:
1. ดูข้อมูลร้าน: `node tools/shop-admin.mjs show รหัสร้าน` (ช่องติดต่อ) และชื่อเจ้าของ เลขผู้เสียภาษีในเมนู 10 ถ้าเจ้าของเข้าไม่ได้ ใช้ข้อมูลตอนเปิดร้าน
2. **โทรกลับไปที่เบอร์ที่ร้านให้ไว้** (ไม่ใช่เบอร์ที่โทรเข้ามา) แล้วถามชื่อ-นามสกุลเจ้าของและเลขผู้เสียภาษีของร้าน
3. ตรงกันแล้วจึงตั้งรหัสใหม่:
   ```
   node tools/shop-admin.mjs password รหัสร้าน --by ชื่อของคุณ
   ```
   รหัสเดิมใช้ไม่ได้ทันที เครื่องที่เข้าระบบค้างไว้ด้วยบัญชีนี้ถูกออกจากระบบ และที่ล็อกเพราะกรอกผิดหลายครั้งถูกปลดล็อก
4. บอกรหัสชั่วคราวทางโทรศัพท์ แล้วให้เจ้าของเปลี่ยนเองทันทีหลังเข้าระบบ

- Franchise: ค่าตั้งต้นคือบัญชี HQ ถ้าชื่อผู้ใช้ของ HQ ไม่ใช่ `hq` ใส่ `--user ชื่อผู้ใช้`
- พนักงานของร้านลืมรหัส: **ไม่ใช่งานของทีมงาน** ให้เจ้าของร้านตั้งให้ในเมนู 10 (Franchise: หัวหน้าสาขาลืมรหัส HQ ตั้งให้)

## งานทุกคืน: ลบข้อมูลร้านที่ครบกำหนด และร้านที่ต้องโทรแจ้ง

ทุกคืนเวลา 03:17 น. (เวลาไทย) งาน **nightly** ของแอป (`tools/nightly.mjs`) ทำเอง:
- ลบข้อมูลของร้านที่หมดอายุครบกำหนด (90 วันหลังวันสุดท้าย) **เฉพาะร้านที่ทีมงานจดว่าโทรแจ้งแล้วอย่างน้อย 30 วัน** เก็บประวัติการเปลี่ยนแปลงไว้อีก 5 ปีแล้วจึงลบ
- ลบไฟล์แนบที่ถูกลบเกิน 30 วัน และไฟล์ที่อัปโหลดแล้วไม่ถูกบันทึกเกิน 1 วัน

**งานไม่แจ้งร้านเอง** (ยังไม่มีระบบอีเมล ช่วงนำร่องทีมงานโทรแจ้ง) เมื่อมีร้านที่ถึงเวลาแจ้ง (30 วันก่อนวันลบ) งานจะจบแบบ "ล้ม"
แล้ว DigitalOcean ส่ง**อีเมลแจ้งเตือน** (job failed) ทุกคืนจนกว่าจะจดว่าแจ้งแล้ว ร้านที่ยังไม่ได้แจ้งจะไม่ถูกลบข้อมูล

เมื่อได้อีเมลแจ้งเตือน:
1. Apps → **drivego-test** → ส่วนประกอบ **nightly** → แท็บ **Logs** (หรือ Activity → การรันล่าสุด) ดูบรรทัด **`CALL`**
   บอกรหัสร้าน ชื่อ ผู้ติดต่อ วันหมดอายุ และวันลบ ถ้า**ไม่มีบรรทัด `CALL`** แปลว่างานล้มจริง ส่ง log ให้ Claude (log ไม่มีรหัส)
2. โทรหาร้าน (ผู้ติดต่อในบรรทัด `CALL` หรือ `node tools/shop-admin.mjs show รหัสร้าน`) บอกว่า:
   หมดอายุแล้ว ข้อมูลจะถูกลบในวันที่บอก ให้ส่งออกข้อมูลที่ต้องเก็บ (เอกสารบัญชีและภาษีต้องเก็บ 5 ปี) หรือต่ออายุก่อนวันนั้น
3. คุยกับร้านได้แล้วจึงจด (เปิด Console ตามหัวข้อแรก):
   ```
   node tools/shop-admin.mjs told รหัสร้าน --note "คุยกับคุณ... วันที่..." --by ชื่อของคุณ
   ```
   เครื่องมือบอกวันลบ (อย่างน้อย 30 วันนับจากวันที่จด ถ้าแจ้งช้าวันลบเลื่อนให้เอง)
   **โทรไม่ติดอย่าจด** ลองใหม่วันถัดไป หรือเลื่อนวันลบด้วย `postpone` (หัวข้อถัดไป)
4. ร้านต่ออายุ: `renew` ตามปกติ วันลบหายไปเอง

บรรทัด **`DEMO`** คือร้านตัวอย่างของ DriveGo (`demo-biz` `demo-prox` `demo-franchise`) ที่หมดวันทดลอง ไม่มีการแจ้งเตือนและไม่ถูกลบ
เปิดทดลองใหม่ได้ด้วย `node tools/shop-admin.mjs open demo-biz --trial --by ชื่อของคุณ`

ดูว่าวันนี้มีอะไรถึงกำหนดโดยไม่เปลี่ยนอะไร: `node tools/retention.mjs`

## เมื่อได้อีเมลแจ้งเตือน

อีเมลจาก DigitalOcean ไปที่อีเมลของบัญชี มีแบบต่อไปนี้ (ดูชื่อในหัวข้ออีเมล):

| แจ้งเตือน | แปลว่า | ทำอะไร |
|---|---|---|
| Uptime: **drivego-test is down** | เว็บไม่ตอบ หรือแอปต่อฐานข้อมูลไม่ได้ | เปิด URL ของแอปดู → Apps → drivego-test → **Activity** (deploy ล่าสุดล้มไหม) และ **Runtime Logs** ของ web → ส่ง log ให้ Claude |
| **nightly** job failed | มีร้านต้องโทรแจ้ง (บรรทัด `CALL`) หรืองานล้มจริง | หัวข้อ "งานทุกคืน" ข้างบน |
| **watch** job failed | server ล้มกับคำขอของผู้ใช้ (`STAFF ACTION NEEDED: the server failed`) หรือหน้าจอผิดพลาดหลายครั้งในชั่วโมงเดียว | ข้างล่าง |
| Restart count / Memory / CPU ของ **web** | แอปล่มซ้ำ ๆ หรือเครื่องทำงานหนักเกิน | Runtime Logs ของ web → ส่งให้ Claude ถ้าเกิดบ่อยอาจต้องเครื่องใหญ่ขึ้น |
| Deployment failed | deploy เวอร์ชันใหม่ไม่ผ่าน เวอร์ชันเดิมยังทำงานอยู่ | Activity → deploy ที่ล้ม → log ของ migrate / web → ส่งให้ Claude |

**ข้อผิดพลาดของระบบ (งาน watch)**: ทุกชั่วโมงงาน watch ดูข้อผิดพลาดที่บันทึกไว้ตั้งแต่ครั้งก่อน
(server ล้มกับคำขอ และข้อผิดพลาดบนหน้าจอที่โปรแกรมไม่ได้จับ ผู้ใช้ไม่เห็นอะไร) แจ้งเตือนเมื่อ server ล้มแม้ครั้งเดียว
หรือหน้าจอผิดพลาด 10 ครั้งขึ้นไปในชั่วโมงนั้น
1. log ของการรันนั้น (ส่วนประกอบ **watch** → Logs): หนึ่งบรรทัดต่อข้อความ `SERVER ×จำนวน รหัสร้าน หน้า เวลา — ข้อความ`
2. รายละเอียด (stack, ผู้ใช้, เบราว์เซอร์) ใน Console:
   ```
   node tools/errors.mjs --hours 24 [--shop รหัสร้าน] [--source server|browser] [--full]
   ```
3. ส่งผลให้ Claude (ข้อความ error ไม่มีรหัสผ่าน แต่อาจมีชื่อร้านหรือข้อมูลที่ผู้ใช้พิมพ์ ส่งเฉพาะทางที่ตกลงกันไว้)
   ถ้าเกิดกับร้านเดียว โทรถามร้านว่ากำลังทำอะไรอยู่

ข้อผิดพลาดเก็บ 30 วัน (งานทุกคืนลบที่เก่ากว่า) และหายไปพร้อมข้อมูลของร้านเมื่อร้านถูกลบ

## วันหมดอายุ (งาน 3.15)

```
node tools/shop-admin.mjs list [--expiring 30]                 ร้านทั้งหมด (หรือที่หมดอายุภายใน 30 วัน)
node tools/shop-admin.mjs show รหัสร้าน                          วันหมดอายุและประวัติของร้าน
node tools/shop-admin.mjs renew รหัสร้าน --years 1 [--paid-on 2026-11-05] [--note "สลิป ..."]
node tools/shop-admin.mjs postpone รหัสร้าน --days 30          เลื่อนวันลบข้อมูลของร้านที่หมดอายุ
node tools/shop-admin.mjs close รหัสร้าน [--last-day 2026-12-31]   ร้านเลิกใช้: ดูได้อย่างเดียว ลบข้อมูล 90 วันหลังจากนั้น
node tools/shop-admin.mjs contact รหัสร้าน "คุณ... 081-..."      ผู้ติดต่อเรื่องต่ออายุ
node tools/shop-admin.mjs told รหัสร้าน [--note "..."]          จดว่าโทรแจ้งร้านแล้วว่าข้อมูลจะถูกลบ (หัวข้อ "งานทุกคืน")
```

ทุกคำสั่งต่อท้าย `--by ชื่อของคุณ`
