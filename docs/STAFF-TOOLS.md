# เครื่องมือทีมงาน DriveGo (เปิดร้าน ลืมรหัสผ่าน วันหมดอายุ)

สำหรับทีมงาน DriveGo เท่านั้น ร้านค้าใช้ไม่ได้ เครื่องมือทั้งหมดอยู่ใน `tools/shop-admin.mjs` รันด้วยรหัสเจ้าของฐานข้อมูล
(doadmin ของ DigitalOcean) ทุกคำสั่งถูกจดในประวัติ (`licence_log`) พร้อมชื่อคนที่รัน (`--by ชื่อ`)

## วิธีรันบน server ทดสอบ (DigitalOcean)

1. DigitalOcean → Apps → **drivego-test** → ส่วนประกอบ **web** → แท็บ **Console** (เปิด shell ในเครื่องที่รันแอปอยู่)
2. คัดลอกข้อความเชื่อมต่อของ **doadmin**: Databases → drivego-test-db → Connection Details → User: doadmin · Connection string
3. ใน Console พิมพ์ (วางข้อความเชื่อมต่อแทน `...` ภายในเครื่องหมาย `'`) ครั้งเดียวต่อการเปิด Console:
   ```
   export MIGRATE_DATABASE_URL='...'
   ```
   **ห้ามวางข้อความนี้ในแชต อีเมล หรือที่อื่น** (เป็นรหัสที่แก้ข้อมูลได้ทุกร้าน) ปิด Console แล้วค่านี้หายไปเอง
4. รันคำสั่งด้านล่าง ต่อท้ายด้วย `--by ชื่อของคุณ` เสมอ

ในเครื่องตัวเอง (`npm run dev`) ใช้ข้อความ `owner database:` ที่ขึ้นตอนเปิดแทนได้

## เปิดร้านจริง

ร้านใหม่เป็นร้านว่าง (ไม่มีข้อมูลตัวอย่าง) มีบัญชีเจ้าของร้าน และวันทดลองใช้ 60 วัน (`--trial`) หรืออู่นำร่อง 1 ปี (`--pilot`)

```
node tools/shop-admin.mjs new รหัสร้าน --biz --pilot --name "ชื่อร้าน" --owner "ชื่อ นามสกุลเจ้าของ" \
  --tax-id 0105545001234 --addr "ที่อยู่" --zip 52000 --tel 0812345678 --email owner@example.com \
  --contact "คุณ... 081-..." --by ชื่อของคุณ
```

- **รหัสร้าน** คือที่อยู่ของร้าน `https://<โดเมน>/รหัสร้าน/` ใช้ตัวพิมพ์เล็ก ตัวเลข และขีด 3–32 ตัว เช่น `daeng-garage` เปลี่ยนทีหลังไม่ได้
- แพ็กเกจ: `--biz` `--prox` หรือ `--franchise` (เครือแฟรนไชส์: ได้บัญชี HQ ชื่อ `hq` ยังไม่มีสาขา HQ เพิ่มสาขาเองในโปรแกรม)
- `--name` และ `--owner` ต้องมี ที่เหลือใส่เท่าที่มี (Biz/ProX: ข้อมูลเหล่านี้จะไปอยู่ในเมนู 10 ตั้งค่าองค์กรตอนเจ้าของเข้าครั้งแรก)
- ชื่อผู้ใช้ของเจ้าของ = รหัสร้านที่ตัดขีดออก (เช่น `daenggarage`) เปลี่ยนได้ด้วย `--user` เจ้าของเข้าด้วยอีเมลก็ได้
- `--from 2026-11-01` เริ่มนับวันจากวันอื่น (ค่าตั้งต้นคือวันนี้)
- เครื่องมือแสดง**รหัสผ่านชั่วคราวครั้งเดียว** บอกเจ้าของร้านทางโทรศัพท์ แล้วให้เปลี่ยนเองหลังเข้าระบบ
  (Biz/ProX: ปุ่ม 🔑 ในแถบเจ้าของร้าน · Franchise: ปุ่มเปลี่ยนรหัสผ่านของบัญชี) **ไม่ส่งรหัสทางแชตหรืออีเมล ไม่จดไว้**

## เจ้าของร้านลืมรหัสผ่าน

ก่อนให้รหัสใหม่ **ต้องยืนยันว่าเป็นเจ้าของร้านจริง**:
1. ดูข้อมูลร้าน: `node tools/shop-admin.mjs show รหัสร้าน` (ช่องติดต่อ) และชื่อเจ้าของ เลขผู้เสียภาษีในเมนู 10 ถ้าเจ้าของเข้าไม่ได้ ใช้ข้อมูลตอนเปิดร้าน
2. **โทรกลับไปที่เบอร์ที่ร้านให้ไว้** (ไม่ใช่เบอร์ที่โทรเข้ามา) แล้วถามชื่อ-นามสกุลเจ้าของและเลขผู้เสียภาษีของร้าน
3. ตรงกันแล้วจึงตั้งรหัสใหม่:
   ```
   node tools/shop-admin.mjs password รหัสร้าน --by ชื่อของคุณ
   ```
   รหัสเดิมใช้ไม่ได้ทันที เครื่องที่เข้าระบบค้างไว้ด้วยบัญชีนี้ถูกออกจากระบบ และที่ล็อกเพราะกรอกผิดหลายครั้งถูกปลดล็อก
4. บอกรหัสชั่วคราวทางโทรศัพท์ แล้วให้เจ้าของเปลี่ยนเองทันทีหลังเข้าระบบ

- Franchise: ค่าตั้งต้นคือบัญชี HQ ถ้าชื่อผู้ใช้ของ HQ ไม่ใช่ `hq` ใส่ `--user ชื่อผู้ใช้`
- พนักงานของร้านลืมรหัส: **ไม่ใช่งานของทีมงาน** ให้เจ้าของร้านตั้งให้ในเมนู 10 (Franchise: หัวหน้าสาขาลืมรหัส HQ ตั้งให้)

## วันหมดอายุ (งาน 3.15)

```
node tools/shop-admin.mjs list [--expiring 30]                 ร้านทั้งหมด (หรือที่หมดอายุภายใน 30 วัน)
node tools/shop-admin.mjs show รหัสร้าน                          วันหมดอายุและประวัติของร้าน
node tools/shop-admin.mjs renew รหัสร้าน --years 1 [--paid-on 2026-11-05] [--note "สลิป ..."]
node tools/shop-admin.mjs postpone รหัสร้าน --days 30          เลื่อนวันลบข้อมูลของร้านที่หมดอายุ
node tools/shop-admin.mjs close รหัสร้าน [--last-day 2026-12-31]   ร้านเลิกใช้: ดูได้อย่างเดียว ลบข้อมูล 90 วันหลังจากนั้น
node tools/shop-admin.mjs contact รหัสร้าน "คุณ... 081-..."      ผู้ติดต่อเรื่องต่ออายุ
```

ทุกคำสั่งต่อท้าย `--by ชื่อของคุณ`
