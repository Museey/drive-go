# ข้อความใหม่ของเฟส 3 (งาน 3.3–3.10) ที่เจ้าของโปรเจกต์อนุมัติแล้ว

ข้อความบนหน้าจอและเอกสารพิมพ์ที่ระบบเดิมไม่มี (กติกาข้อ 7: ข้อความต้องเหมือนระบบเดิม ข้อความใหม่ต้องได้รับอนุมัติ)
รวบรวมจากโค้ดจริงเทียบกับระบบเดิมเมื่อ 2026-10-27 · "…" คือส่วนที่ระบบเติมเอง (เลขที่ วันที่ ชื่อ จำนวนเงิน)

**เจ้าของโปรเจกต์อนุมัติทั้งหมดตามที่เสนอ แชต 2026-10-27** ไฟล์นี้จึงเป็นรายการที่อนุมัติแล้ว (NOTES.md ของแต่ละงานอ้างมาที่นี่)
ข้อความใหม่ที่เกิดหลังจากนี้ต้องขออนุมัติใหม่ตามกติกาข้อ 7

อนุมัติไว้ก่อนหน้า (ไม่อยู่ในไฟล์นี้): ข้อความ Q5 (บันทึกชนกัน เน็ตหลุด หมดเวลาเข้าระบบ), T12 (ไม่คิด VAT ยกเลิกใบกำกับ ชื่อสิทธิ์ใหม่ 3 ตัว),
เลขที่เอกสารที่ server เปลี่ยนให้ (3.2), การป้องกันการแทนที่ข้อมูลทั้งร้าน (3.2d), งาน 3.11–3.15

## 1. ปิดงวดภาษี (งาน 3.3, รายงานภาษีและหน้า 4.6)

1. ปุ่ม "ปิดงวดภาษี" ที่หัวรายงานภาษี และป้าย "ปิดงวดภาษีแล้ว" ตามด้วยวันที่ · ชื่อผู้ปิด
2. การ์ดยืนยัน: หัวข้อ "ปิดงวดภาษีเดือน …?" ข้อความ "หลังปิดงวด เอกสารที่มี VAT ของเดือนนี้แก้ได้ด้วยใบลดหนี้เท่านั้น" ปุ่ม "ปิดงวดภาษี" / "ยังไม่ปิด"
3. หลังปิด: "ปิดงวดภาษีเดือน … แล้ว"
4. ปุ่ม "เปิดงวดกลับ" (เจ้าของ) การ์ด "เปิดงวดภาษีเดือน … กลับ" ช่อง "เหตุผลที่เปิดงวดกลับ" ปุ่ม "เปิดงวดกลับ" / "ยกเลิก" แล้วขึ้น "เปิดงวดภาษีเดือน … กลับแล้ว"
5. แก้เอกสารของเดือนที่ปิดแล้ว: "เดือน … ปิดงวดภาษีแล้ว ใช้ใบลดหนี้แทน"
6. ออกใบกำกับเต็มรูปของการขายในเดือนที่ปิดแล้ว: การ์ด "เดือน … ปิดงวดภาษีแล้ว" ข้อความ
   "ใบกำกับภาษีเต็มรูปลงวันที่ขาย … รายงานภาษีขายของเดือนนั้นยังแสดงเลขเดิม … และยอดภาษีไม่เปลี่ยน" ปุ่ม "ออกใบกำกับภาษี" / "ไม่ออก"
7. ทะเบียน 4.6 ใต้เลขที่เดิม: "ออกใบเต็มรูปภายหลัง เลขที่ …"
8. ประวัติการใช้งาน: "ปิดงวดภาษีเดือน …", "เปิดงวดภาษีเดือน … กลับ · เหตุผล: …"

## 2. ใบลดหนี้ (งาน 3.3, หน้า 4.6)

1. ปุ่ม "+ ออกใบลดหนี้" ข้าง "+ ออกใบกำกับภาษีใหม่"
2. หน้าต่างเลือกการขาย: หัว "ออกใบลดหนี้" ช่อง "ค้นหาเลขที่ใบตัดสต็อก / ใบกำกับภาษี / ชื่อลูกค้า"
   คอลัมน์ "เลขที่ใบตัดสต็อก", "ใบกำกับภาษี", "วันที่", "ลูกค้า", "ยอดขาย" ไม่มีรายการ: "ไม่พบการขายที่มี VAT ที่ออกใบลดหนี้ได้"
3. ฟอร์ม: หัว "ออกใบลดหนี้ · ใบตัดสต็อก …" บรรทัด "… · ขายวันที่ … · ยอดขาย … บาท · คงค้าง … บาท · ลดได้อีก … บาท"
4. "กรณี": "ลูกค้าคืนสินค้า", "ลดราคาหลังขาย", "ยอดในใบกำกับภาษีเกินจริง (คิดเงินผิด)", "ยกเลิกการขายทั้งใบ"
5. ตารางสินค้า: "รหัส", "รายการ", "ขาย", "คืนแล้ว", "จำนวนที่คืน", "ราคา/หน่วย", "สินค้าที่คืน" (เลือก "คืนเข้าสต๊อก" / "ของเสีย")
   ไม่มีรายการ: "ไม่มีรายการสินค้าในสต๊อกที่คืนได้"
6. ช่อง "มูลค่าที่ลด (ก่อน VAT)", "เหตุผล (ต้องกรอก)", "คืนเงินโดย" (เงินสด / เงินโอน) ปุ่ม "บันทึกใบลดหนี้"
7. สรุปยอด: "มูลค่าที่ลด (ก่อน VAT)", "ภาษีมูลค่าเพิ่ม …%", "รวมใบลดหนี้", "ลดยอดค้างชำระ", "คืนเงินให้ลูกค้า"
8. ข้อความเตือน: "บัญชีนี้ไม่มีสิทธิ์ออกใบลดหนี้", "ใบตัดสต็อก … ออกใบลดหนี้ไม่ได้", "ใส่จำนวนสินค้าที่คืนก่อน", "ใส่มูลค่าที่ลดก่อน",
   "ใบลดหนี้ลดได้ไม่เกิน … บาท", "ใส่เหตุผลของใบลดหนี้ก่อน"
9. หลังบันทึก: "ออกใบลดหนี้ … แล้ว" (เจ้าของ) / "ส่งใบลดหนี้ … ขออนุมัติแล้ว" (พนักงาน) และการอนุมัติ "อนุมัติใบลดหนี้ … แล้ว" / "ไม่อนุมัติใบลดหนี้ … แล้ว"
10. หน้าต่างดูใบลดหนี้: หัว "ใบลดหนี้ …" บรรทัด "… · วันที่ … · อ้างอิง … ลงวันที่ … · ใบตัดสต็อก …", "กรณี: … · เหตุผล: …"
    ปุ่ม "ไม่อนุมัติ" / "อนุมัติ" / "พิมพ์ใบลดหนี้ (ต้นฉบับ + สำเนา)" ในหน้าต่างการขายมีปุ่ม "ใบลดหนี้ …" (ต่อท้าย " · รออนุมัติ" ถ้ายังไม่อนุมัติ)
11. การขายที่มีใบลดหนี้: "ใบตัดสต็อก … มีใบลดหนี้ … แล้ว — ยกเลิกหรือทำฉบับแก้ไขไม่ได้ ใช้ใบลดหนี้แทน", "รายการนี้มาจากใบลดหนี้ … — ลบไม่ได้"
12. ใบลดหนี้ที่พิมพ์: "ใบลดหนี้" / "CREDIT NOTE", "เลขที่", "วันที่", "อ้างอิงใบกำกับภาษีเลขที่", "ลงวันที่", "ชื่อผู้ซื้อ / ผู้รับบริการ",
    "เลขประจำตัวผู้เสียภาษี", "ลำดับ / รหัส / รายการ / จำนวน / หน่วยละ / จำนวนเงิน", "มูลค่าสินค้าหรือบริการตามใบกำกับภาษีเดิม", "มูลค่าที่ถูกต้อง",
    "ผลต่าง", "ภาษีมูลค่าเพิ่ม …%", "รวมทั้งสิ้น", "เหตุผลที่ลดหนี้", "ผู้ออกใบลดหนี้", "ผู้รับใบลดหนี้", "ต้นฉบับ" / "สำเนา"
13. รายการเคลื่อนไหวสต๊อก: "รับคืนตามใบลดหนี้ … · ใบตัดสต็อก …" ประวัติการพิมพ์: "ใบลดหนี้ … 2 แผ่น"

## 3. ใบสำคัญจ่าย และหัก ณ ที่จ่ายผู้ขาย (งาน 3.4)

1. ใบสำคัญจ่ายที่พิมพ์: "ใบสำคัญจ่าย" / "PAYMENT VOUCHER", "วันที่จ่าย", "จ่ายให้", "จ่ายจริง", "วิธีจ่าย", ลงชื่อ "ผู้จ่ายเงิน", "ผู้อนุมัติ", "ผู้รับเงิน"
   รายการ "ค่าสินค้าตามใบรับสินค้า … (ใบกำกับ / ใบส่งของ …)"
2. ปุ่ม "พิมพ์ใบสำคัญจ่าย" (รายจ่าย จ่ายเจ้าหนี้)
3. หน้าจ่ายเจ้าหนี้: ปุ่ม "หัก ณ ที่จ่าย" ตาราง "หัก ณ ที่จ่ายผู้ขาย" คอลัมน์ "ฐานก่อน VAT", "อัตรา", "ยอดหัก (บาท)" ยังไม่เลือกบิล: "ติ๊กใบรับสินค้าที่จะจ่ายก่อน"
4. สรุป: "หัก ณ ที่จ่าย รวม … — ยอดที่ต้องจ่ายผู้ขาย …"
   คำอธิบาย: "ยอดที่หักไม่ใช่เงินที่จ่าย — ระบบลดยอดคงค้างของบิลนั้นให้ · ออกหนังสือรับรอง (50 ทวิ) ได้ที่ 4.4 ใบหัก ณ ที่จ่าย · เราหักผู้ขาย"
5. การ์ดตรวจก่อนบันทึก: "หัก ณ ที่จ่าย ฿… — ไม่ใช่เงินที่จ่าย ระบบลดยอดคงค้างของบิลให้"
6. ข้อความเตือน: "ยอดหัก ณ ที่จ่ายต้องน้อยกว่ายอดคงค้างของบิล", "ยังไม่ได้จ่ายเงิน — ออก 50 ทวิ ได้หลังจ่าย"
7. ประวัติการใช้งาน: "จ่ายเงิน … บาท (…) · หัก ณ ที่จ่าย … บาท · ใบสำคัญจ่าย …"
8. หนังสือรับรอง 50 ทวิ ใช้ถ้อยคำตามแบบของกรมสรรพากรทั้งหมด (ให้ผู้ทำบัญชีตรวจแบบ ไม่ใช่ข้อความที่เราแต่งเอง)

## 4. การรับเงินและค่าธรรมเนียมบัตร (งาน 3.5)

1. "ยอดตามใบตัดสต็อก"
2. "ค่าธรรมเนียมบัตรเครดิต …%" / "ค่าธรรมเนียมบัตรเดบิต …%"
3. การ์ดตรวจก่อนบันทึก: "ค่าธรรมเนียมบัตร …% ฿… — ยอดที่ต้องรูดรวม ฿…"
4. รายงานประจำวัน: "ค่าธรรมเนียมบัตรที่ลูกค้าจ่ายเพิ่มวันนี้ … บาท — ไม่ใช่รายได้ ใช้หักกับค่าธรรมเนียมที่ธนาคารเก็บ (ไม่รวมในยอดบัตรข้างบน)"
5. รายงานประจำวัน: "คืนเงินลูกค้าตามใบลดหนี้ — จ่ายออกจากเงินของวันนี้"

## 5. สต๊อกแบบ FIFO (งาน 3.6)

1. ขายเกินของที่มี: "อะไหล่ … รายการมีไม่พอ — ตัดสต็อกติดลบได้เฉพาะเจ้าของหรือผู้มีสิทธิ์อนุมัติเอกสาร"
2. ใบเบิก: ช่อง "หมวดค่าใช้จ่าย" และ "ลงบัญชีตามทุน FIFO: ค่าใช้จ่ายหมวด … … บาท"
3. ใบตรวจนับ: "ลงบัญชีตามทุน FIFO: ค่าใช้จ่ายสินค้าขาด … บาท · รายได้อื่น (สินค้าเกิน) … บาท"
4. ขายของที่ขาดให้ผู้รับผิดชอบ: ปุ่ม "เปิดใบขายให้ผู้รับผิดชอบ", "ดึงของที่ขาดจากใบตรวจนับ … แล้ว — เลือกลูกค้า (ผู้รับผิดชอบ) แล้วบันทึกการขาย",
   "ขายของที่ขาดให้ผู้รับผิดชอบแล้ว: …", "ไม่มีของขาดที่ยังไม่ได้เปิดใบขาย", "ใบตรวจนับ … มีใบขายของที่ขาด … — ยกเลิกใบขายก่อน"
5. ประวัติการใช้งานและรายการเคลื่อนไหว: "ขายของที่ขาดให้ผู้รับผิดชอบ · ใบตัดสต็อก … · …", "ยกเลิกใบตัดสต็อก … · กลับเป็นของขาด …",
   "รับของจากคลังกลาง ProX · คำขอ #…"
6. งบการเงิน: "สินค้าขาดจากการตรวจนับ", "บวก รายได้อื่น (สินค้าเกินจากการตรวจนับ)"
7. รับของจากคลังกลางที่สาขายังไม่มีสินค้านั้น: การ์ด "ทุนของสินค้าใหม่" ข้อความ
   "สินค้า … รายการยังไม่มีในทะเบียนของสาขา — กรอกทุนต่อหน่วย (ใช้เป็นต้นทุน FIFO และทุนในทะเบียน)" ช่อง "ทุนต่อหน่วย"
   ปุ่ม "รับของเข้าสต๊อก" / "ยังไม่รับ" และ "กรอกทุนต่อหน่วยของสินค้าใหม่ให้ครบทุกรายการ"

## 6. เงินเดือนและประกันสังคม (งาน 3.7, หน้า 06.4 จ่ายเงินเดือน)

1. ข้อมูลพนักงาน: ช่อง "เงินได้ประจำ (บาท/เดือน)" และ "เงินได้ประจำ …" ในรายชื่อพนักงาน
2. ประกันสังคม: "ประกันสังคมตามกฎหมาย (ตั้งแต่ …): …% ฐาน … – … · หักสูงสุด … บาท — ระบบปรับให้เอง"
3. ร้านตั้งอัตราเอง: การ์ด "อัตราประกันสังคมต่างจากกฎหมาย" ข้อความ "ตามกฎหมาย: …% ฐาน … – … บาท หักสูงสุด … บาท",
   "ที่กรอก: …% ฐาน … – … บาท หักสูงสุด … บาท", "ใช้ค่าที่กรอกกับเงินเดือนตั้งแต่งวด … เป็นต้นไป — ระบบจะไม่ปรับตามกฎหมายให้จนกว่าจะกลับไปใช้ค่าตามกฎหมาย"
   ปุ่ม "ใช้ค่าที่ร้านตั้ง" / "ไม่เปลี่ยน" แล้วแสดง "ตอนนี้ใช้ค่าที่ร้านตั้งเอง (…% · ฐาน … – … · หักสูงสุด …) ตั้งแต่ … โดย …" ป้าย "ร้านตั้งเอง"
   ประวัติ "ตั้งอัตราประกันสังคมเอง …% ฐาน … – … หักสูงสุด … บาท ตั้งแต่ … (กฎหมาย: …)" / "กลับไปใช้อัตราประกันสังคมตามกฎหมาย"
4. สถานะงวด: "ยังไม่ได้บันทึก… — กรอกค่าล่วงเวลา เงินพิเศษ และภาษีหัก ณ ที่จ่ายของงวดนี้ (ถ้ามี) แล้วกด "บันทึกจ่ายเงินเดือนงวดนี้"",
   "บันทึกแล้ว · รายจ่าย … (เงินเดือน) และ … (นายจ้างสมทบ)"
5. การ์ด "บันทึกเงินเดือน …": "ลงค่าใช้จ่ายวันที่ … (สิ้นงวด)", "สถานะ", "ค้างจ่าย (จ่ายทีหลัง)", "วันที่จ่าย", "วิธีจ่าย"
   หลังบันทึก "บันทึกเงินเดือน … แล้ว · เงินเดือน … + สมทบนายจ้าง … บาท · จ่ายแล้ว" (หรือ "· ค้างจ่าย")
   บันทึกซ้ำ: "… บันทึกแล้ว (…) — ต้องยกเลิกงวดเดิมก่อนจึงจะบันทึกใหม่ได้"
6. จ่ายและนำส่ง: ปุ่ม "จ่ายเงินเดือน", "นำส่งประกันสังคม" การ์ด "จ่ายเงินเดือน …" (ปุ่ม "บันทึกการจ่าย"), "นำส่งประกันสังคม …" (ปุ่ม "บันทึกการนำส่ง")
   หลังบันทึก "บันทึกจ่ายเงินเดือน … แล้ว · ใบสำคัญจ่าย …", "บันทึกนำส่งประกันสังคม … แล้ว · ใบสำคัญจ่าย …"
   สถานะ "เงินเดือนค้างจ่าย", "ประกันสังคมค้างนำส่ง" ประวัติ "จ่ายเงินเดือน … สุทธิ … บาท", "นำส่งประกันสังคม … … บาท (ลูกจ้าง … + นายจ้าง …)"
7. ยกเลิกงวด: ปุ่ม "ยกเลิกงวดนี้" การ์ด "ยกเลิกเงินเดือน …" ข้อความ "ระบุเหตุผลที่ยกเลิก (จำเป็น)" และ
   "รายจ่าย … และ … ของงวดนี้จะถูกยกเลิก (รวมการจ่ายที่บันทึกไว้ (…)) แล้วบันทึกงวดใหม่ได้" ปุ่ม "ยกเลิกงวดนี้" / "ไม่ยกเลิก"
   หลังยกเลิก "ยกเลิกเงินเดือน … แล้ว — บันทึกงวดใหม่ได้" แสดง "ยกเลิก … โดย …" ประวัติ "ยกเลิกเงินเดือน … — <เหตุผล> · …"
8. รายจ่ายที่มาจากเงินเดือน: "รายจ่ายนี้เป็นของเงินเดือน … — ยกเลิกที่หน้า 06.4 จ่ายเงินเดือน",
   "รายจ่ายนี้เป็นของเงินเดือน … — แก้ไขที่หน้า 06.4 จ่ายเงินเดือน (ยกเลิกงวดแล้วบันทึกใหม่)"
9. รายละเอียดรายจ่าย: "จ่ายเงินเดือนและค่าล่วงเวลา …" ("หักประกันสังคมลูกจ้าง … บาท · หักภาษี ณ ที่จ่าย … บาท · จ่ายสุทธิ … บาท", ผู้รับ "พนักงาน … คน"),
   "เงินสมทบประกันสังคมส่วนนายจ้าง …" ("นำส่งพร้อมส่วนลูกจ้าง รวม … บาท", ผู้รับ "สำนักงานประกันสังคม")
10. สิทธิ์: "บัญชีนี้ไม่มีสิทธิ์บันทึกเงินเดือน (ต้องมีสิทธิ์บันทึกค่าใช้จ่าย)"
11. เตือนว่ายังไม่บันทึก: "ยังไม่ได้บันทึกเงินเดือน … เดือน (… – …) — งบและเงินสดยังไม่มีเงินเดือนของเดือนเหล่านั้น (บันทึกที่ 06.4 จ่ายเงินเดือน)",
    "ยังไม่ได้บันทึกเงินเดือน… (06.4 จ่ายเงินเดือน)" หน้าแรก "… คน · ประมาณการ" / "… คน · บันทึกแล้ว"
12. งบการเงิน: "จ่ายเงินเดือนและประกันสังคม", "เงินสดจ่ายเงินเดือนและประกันสังคม", "เงินเดือนค้างจ่าย", "ประกันสังคมค้างนำส่ง"
13. สลิปเงินเดือน: ปุ่ม "สลิปเงินเดือน", "พิมพ์สลิปเงินเดือนทุกคน" แผ่น "สลิปเงินเดือน" / "PAY SLIP" ("สำหรับพนักงาน"), "งวด",
    "เงินเดือน (… วัน: … – … · อัตรา …)" (เดือนที่ทำงานไม่เต็ม), "เงินได้ประจำ", "ค่าล่วงเวลา", "เงินพิเศษ", "รายการหัก",
    "เงินสมทบประกันสังคม …% (ฐาน …)", "ภาษีเงินได้หัก ณ ที่จ่าย", "รวมรายการหัก", "จ่ายสุทธิให้พนักงาน", "นายจ้างสมทบประกันสังคมให้ … บาท"
    ประวัติการพิมพ์ "สลิปเงินเดือน … · ทุกคน … ใบ"
14. ใบสำคัญจ่ายเงินเดือน: "เงินเดือนและค่าจ้าง … (… คน)", "หัก เงินสมทบประกันสังคม (ส่วนลูกจ้าง)", "หัก ภาษีเงินได้หัก ณ ที่จ่าย (ภ.ง.ด.1)"
    ใบสำคัญจ่ายเงินสมทบ: "เงินสมทบประกันสังคมส่วนลูกจ้าง (หักจากเงินเดือน …)", "เงินสมทบประกันสังคมส่วนนายจ้าง …"

## 7. ภาษีเงินเดือน ภ.ง.ด.1 และ 50 ทวิ ของพนักงาน (งาน 3.8)

1. หน้า 06.4: คอลัมน์และช่อง "ภาษีหัก ณ ที่จ่าย" เกินรายได้: "ภาษีหัก ณ ที่จ่ายของ … ต้องไม่เกินรายได้หลังหักประกันสังคม (… บาท)"
2. "ภาษีหัก ณ ที่จ่ายที่ต้องนำส่ง (ภ.ง.ด.1) ภายในวันที่ 7 ของเดือนถัดจากเดือนที่จ่ายเงินเดือน"
3. การ์ดบันทึกเงินเดือน: "หักภาษีเงินได้ ณ ที่จ่าย (ภ.ง.ด.1)", "ภาษีหัก ณ ที่จ่าย … บาท — นำส่งหลังจ่ายเงินเดือน"
4. นำส่ง: สถานะ "ภาษี ภ.ง.ด.1 ค้างนำส่ง" ปุ่ม "นำส่ง ภ.ง.ด.1" การ์ด "นำส่งภาษีหัก ณ ที่จ่าย (ภ.ง.ด.1) …" ข้อความ
   "(ภาษีเงินได้ที่หักจากเงินเดือน … คน) ภายในวันที่ …" ปุ่ม "บันทึกการนำส่ง" หลังบันทึก "บันทึกนำส่ง ภ.ง.ด.1 … แล้ว · ใบสำคัญจ่าย …"
   สถานะ "นำส่ง ภ.ง.ด.1 แล้ว …" ยังไม่จ่ายเงินเดือน: "ยังไม่ได้จ่ายเงินเดือน … — ภาษีหัก ณ ที่จ่ายนำส่งได้หลังจ่ายเงินเดือน"
5. ประวัติการใช้งาน: "นำส่งภาษีหัก ณ ที่จ่าย (ภ.ง.ด.1) … … บาท (…) · ใบสำคัญจ่าย …", "รอจ่ายเงินเดือน"
   ใบสำคัญจ่าย: "ภาษีเงินได้หัก ณ ที่จ่ายจากเงินเดือน (ภ.ง.ด.1) … (… คน)" ผู้รับ "กรมสรรพากร"
6. รายงานภาษี: "ภาษีเงินเดือนหัก ณ ที่จ่ายที่ต้องนำส่ง (ภ.ง.ด.1) ภายในวันที่ 7 ของเดือนถัดไป (ยื่นแบบกระดาษ) · นับตามวันที่จ่ายเงินเดือน",
   "ฐานเงินเดือนสำหรับ ภ.ง.ด.1", "ภาษีหัก ณ ที่จ่ายนำส่ง (ภ.ง.ด.1)", "นำส่งแล้ว … · ใบสำคัญจ่าย …" / "ยังไม่นำส่ง … บาท" / "ไม่มีภาษีหัก ณ ที่จ่าย"
7. สรุป ภ.ง.ด.1: ปุ่ม "พิมพ์สรุป ภ.ง.ด.1" แผ่น "สรุปภาษีเงินได้หัก ณ ที่จ่าย ภ.ง.ด.1" / "P.N.D.1 SUMMARY" ("เอกสารภายใน"),
   "เดือนที่จ่ายเงินได้", "ผู้มีเงินได้ … ราย", "เลขประจำตัวประชาชน", "ชื่อผู้มีเงินได้", "รวม … ราย (หักภาษี … ราย)",
   "การนำส่ง (ภายในวันที่ 7 … ยื่นแบบกระดาษ)", "เงื่อนไข 1 = หัก ณ ที่จ่าย · ให้ผู้ทำบัญชีตรวจก่อนยื่นแบบ"
   ยังไม่มีข้อมูล: "เดือน … ยังไม่มีเงินเดือนที่จ่ายแล้ว" ประวัติ "สรุป ภ.ง.ด.1 เดือน … · … ราย · ภาษี … บาท"
8. 50 ทวิ ประจำปี: ปุ่ม "พิมพ์ 50 ทวิ ประจำปีของพนักงาน", "ปี … ยังไม่มีเงินเดือนที่จ่ายแล้ว",
   "บัญชีนี้ไม่มีสิทธิ์ออก 50 ทวิ ของพนักงาน (ต้องมีสิทธิ์บันทึกค่าใช้จ่าย)",
   ประวัติ "หนังสือรับรองการหักภาษี ณ ที่จ่าย (50 ทวิ) ปี … · พนักงาน … คน · …" (ตัวแบบ 50 ทวิ ใช้ถ้อยคำของกรมสรรพากร เหมือนข้อ 3.8)
9. ข้อมูลพนักงาน: ช่อง "ที่อยู่ (สำหรับ 50 ทวิ)" ตัวอย่างในช่อง "ที่อยู่ตามบัตรประชาชน"

## 8. สิทธิ์การเห็นข้อมูล (งาน 3.9)

1. "บัญชีนี้ไม่มีสิทธิ์ดูเงินเดือน (ต้องมีสิทธิ์ดูสรุปการเงิน ภาษี และเงินเดือน หรือดูและแก้ไขข้อมูลพนักงาน)"
2. "ส่งออกไฟล์สำรองทั้งร้านได้เฉพาะเจ้าของร้าน"
3. "กู้คืนจากจุดสำรองได้เฉพาะเจ้าของร้าน"
4. "มีสินค้าใหม่ … รายการที่ต้องกรอกทุน — ให้ผู้มีสิทธิ์เห็นต้นทุนรับของเข้าสต๊อก"
5. "บันทึกผลเคลม (รับคืน / ตีเสีย / หักยอด) ต้องให้ผู้มีสิทธิ์เห็นต้นทุนเป็นผู้บันทึก"
6. คำอธิบายในหน้าตั้งสิทธิ์: "งานที่เห็นราคาซื้อ (ใบรับสินค้า อนุมัติใบรับสินค้า จ่ายเงินเจ้าหนี้ เจ้าหนี้ค้างจ่าย ดูสรุปการเงิน) เปิด "แสดงต้นทุน" ให้เองเมื่อบันทึก"

## 9. ทุกเครื่องเห็นการเปลี่ยนแปลงทันที (งาน 3.10)

1. เน็ตหลุด (ปิดทั้งหน้าจอ): "เชื่อมต่อ server ไม่ได้ — ออกเอกสารและรับเงินไม่ได้จนกว่าจะเชื่อมต่อได้ ระบบกำลังลองเชื่อมต่อใหม่"
2. แถบในเอกสารที่เปิดอยู่: "เอกสารนี้ถูกแก้ไขโดย <ชื่อ> เมื่อ <เวลา> — กดเพื่อโหลดข้อมูลล่าสุด"
3. แถบในเอกสารที่เปิดอยู่: "เอกสารนี้ถูกลบโดย <ชื่อ> เมื่อ <เวลา> — กดเพื่อปิด" (<ชื่อ> ของพนักงานเป็น "รหัส · ชื่อ" ของเจ้าของเป็น "เจ้าของกิจการ / ผู้ดูแลระบบ")
4. อีกเครื่องแทนที่ข้อมูลทั้งร้าน: "ล้างข้อมูลทั้งหมดจากเครื่องอื่นแล้ว — กดตกลงเพื่อโหลดข้อมูลล่าสุด"
   (คำแรกเป็น "กู้คืนข้อมูล", "นำเข้าข้อมูล" หรือ "โหลดข้อมูลตัวอย่าง" ตามสิ่งที่ทำ)
