# วิธีลงบัญชีของเอกสารแต่ละชนิด (ร่างสำหรับบัญชีแยกประเภท)

ร่าง 2026-10-29 ตามคำตอบ 8.2 ของผู้ทำบัญชี B (ต้องมีรายงานบัญชีแยกประเภทก่อนนำร่อง) และข้อตัดสินของเจ้าของโปรเจกต์:
ร่างให้ B ตรวจก่อน แล้วจึงเขียนโปรแกรม (ส่งเป็นไฟล์ Excel "ชุดตรวจผู้ทำบัญชี รอบ 3" ไม่ commit) **ยังไม่ได้ทำในโปรแกรม**
เมื่อได้คำตอบแล้วให้แก้ไฟล์นี้เป็นข้อกำหนดที่ตกลงแล้ว (ACCOUNTANT-ANSWERS.md "รอบ 3")

รหัสบัญชีตามผังบัญชีของร้าน (ค่าตั้งต้น `DEFAULT_COA` / `DEFAULT_MAP` ใน `frontend/js/03.js`) ร้านเปลี่ยนรหัสได้ในเมนูผังบัญชี

## คำถามอื่นในรอบ 3

- **Q1 ใบกำกับภาษีของค่าธรรมเนียมบัตร (ต่อจาก 3.2)**: ค่าธรรมเนียมเป็นรายได้อื่นที่มี VAT แล้ว (J05) อยู่ในยอดของเดือนในสรุปภาษี แต่ยังไม่มีเอกสารที่เป็นใบกำกับภาษีของค่าธรรมเนียม ใบเสร็จยังไม่แยก VAT ของค่าธรรมเนียม — เอกสารไหนเป็นใบกำกับภาษีของค่าธรรมเนียม (ก) ใบเสร็จรับเงินที่มีค่าธรรมเนียม แสดง VAT ของค่าธรรมเนียม และเป็นใบกำกับภาษี (อย่างย่อ) ไปด้วย · ข) ออกใบกำกับภาษีแยกสำหรับค่าธรรมเนียม · ค) ไม่ต้องมีเอกสาร รวมยอดในรายงานภาษีขายพอ)
- **Q2 ยกเลิกการรับเงินด้วยบัตรในเดือนที่ปิดงวดภาษีแล้ว**: เดือนที่ปิดงวดภาษีแล้วยังยกเลิกการรับเงินได้ ถ้ารับด้วยบัตรที่มีค่าธรรมเนียม ภาษีขายของค่าธรรมเนียมในเดือนที่ปิดไปแล้วจะเปลี่ยน — ควรทำอย่างไร (ก) ห้ามยกเลิก ให้คืนเงินด้วยใบลดหนี้ในเดือนปัจจุบัน · ข) ยกเลิกได้ ภาษีขายของค่าธรรมเนียมลดในเดือนที่ยกเลิก · ค) ยกเลิกได้ ไม่ต้องทำอะไรกับภาษี)
- **Q3 หน้าตารายงานบัญชีแยกประเภท (ต่อจาก 8.2)**: จะทำจากการลงบัญชีในแผ่น "การลงบัญชี" งบทดลองจะคิดจากรายการเดียวกัน (สมดุลเอง ไม่มีบรรทัดผลต่างจากการประมาณการแบบตอนนี้) — เสนอ: เลือกบัญชีและช่วงวันที่ แสดง วันที่ · เลขที่เอกสาร · คำอธิบาย · เดบิต · เครดิต · ยอดคงเหลือ พร้อมยอดยกมาต้นงวด พิมพ์และส่งออก Excel ได้ ต้องการอะไรเพิ่มไหม (เช่น สมุดรายวันทั่วไป)
- **Q4 เหตุผลของใบลดหนี้ (ต่อจาก 1.10)**: ตอนนี้ใบลดหนี้ต้องกรอกเหตุผลเป็นข้อความ (พิมพ์ลงใบลดหนี้) — ควรให้เลือกเหตุตามมาตรา 82/10 (สินค้าชำรุด ไม่ตรงตามที่ตกลง ขาดจำนวน คิดราคาผิด รับคืน บอกเลิกบริการ) แล้วเขียนรายละเอียดเพิ่มไหม
