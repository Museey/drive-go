# คู่มือเริ่มใช้ DriveGo ระบบใหม่ สำหรับอู่นำร่อง

สำหรับเจ้าของอู่และพนักงานที่เคยใช้ DriveGo แบบไฟล์ (เปิดไฟล์ HTML ในเครื่อง) ใช้ประกอบการสอนการใช้งาน (LAUNCH-CHECKLIST ด่าน 2)
หน้าจอและเมนูเหมือนเดิมเกือบทั้งหมด คู่มือนี้บอกเฉพาะสิ่งที่**ต่างจากเดิม**และสิ่งที่ต้องทำครั้งแรก
ช่องที่เขียนว่า «…» ทีมงานกรอกก่อนให้อู่

## 1. ต่างจากไฟล์เดิมอย่างไร

| เรื่อง | ไฟล์เดิม | ระบบใหม่ |
|---|---|---|
| เปิดใช้งาน | เปิดไฟล์ในเครื่อง | เปิดเว็บ «ที่อยู่เว็บ»/«รหัสร้าน»/ ด้วยเบราว์เซอร์ (Chrome, Edge, Safari) จากคอมพิวเตอร์ แท็บเล็ต หรือมือถือ |
| ข้อมูลอยู่ที่ไหน | ในเครื่องใครเครื่องมัน | ที่ server ทุกเครื่องในอู่เห็นข้อมูลชุดเดียวกัน คนหนึ่งบันทึก เครื่องอื่นเห็นทันที |
| อินเทอร์เน็ต | ไม่ต้องมี | **ต้องมี** ถ้าเน็ตหลุดจะขึ้น "เชื่อมต่อ server ไม่ได้" และออกเอกสาร รับเงิน บันทึกไม่ได้จนเน็ตกลับ (ระบบต่อใหม่เอง) |
| เลขที่เอกสาร | เครื่องออกเอง | server ออกเลขให้ ไม่ซ้ำกันแม้หลายเครื่องออกพร้อมกัน |
| สำรองข้อมูล | ต้องกดสำรอง / เก็บไฟล์เอง | server สำรองให้ทุกวัน (กู้ย้อนได้ 7 วัน) ยังกดสำรอง / ดาวน์โหลดไฟล์แนบทั้งหมด (.zip) ในเมนู 10 ได้ |
| รหัสผ่าน | เก็บในไฟล์ | เก็บแบบเข้ารหัสที่ server ทีมงานเองก็ดูรหัสผ่านไม่ได้ ลืมรหัสต้องให้ทีมงานตั้งใหม่ (ข้อ 6) |
| สองคนแก้เอกสารเดียวกัน | ไม่เกิด (คนละเครื่อง) | ถ้าเอกสารที่เปิดอยู่ถูกคนอื่นแก้ จะขึ้นแถบ "เอกสารนี้ถูกแก้ไขโดย … — กดเพื่อโหลดข้อมูลล่าสุด" |

## 2. วันแรก (เจ้าของอู่)

1. ทีมงานให้ **รหัสร้าน ชื่อผู้ใช้ของเจ้าของ และรหัสผ่านชั่วคราว** (ใช้ได้ครั้งเดียว) เข้าระบบแล้ว**เปลี่ยนรหัสผ่านทันที**
2. เมนู 10 ตั้งค่าองค์กร: ชื่อกิจการ ที่อยู่ เลขประจำตัวผู้เสียภาษี สาขาที่ (สำนักงานใหญ่ / สาขา) จดทะเบียน VAT หรือไม่ บัญชีธนาคาร โลโก้
   (ข้อมูลนี้พิมพ์ลงใบกำกับภาษีและเอกสารทุกใบ ตรวจให้ถูกก่อนออกเอกสารใบแรก)
3. เพิ่มพนักงานและสิทธิ์ (เมนูพนักงาน) ให้ทุกคน**มีบัญชีของตัวเอง** ไม่ใช้บัญชีเจ้าของร่วมกัน ระบบจดว่าใครทำอะไร
4. ผังบัญชี (เมนู 08 → ผังบัญชี) ใช้ผังมาตรฐานได้เลย ถ้าผู้ทำบัญชีใช้รหัสของตัวเอง แก้ที่นี่ก่อนเริ่ม
5. **ยอดยกมา** (เมนู 08 → ยอดยกมา): ถ้าอู่ใช้โปรแกรมอื่นหรือทำบัญชีมาก่อน ให้ผู้ทำบัญชีกรอกยอดของทุกบัญชี ณ วันก่อนวันเริ่มใช้
   (เงินสด ธนาคาร ลูกหนี้ เจ้าหนี้ สินทรัพย์ ทุน ภาษีซื้อที่ยกมา) ไม่กรอก งบทดลองและงบการเงินจะเริ่มจากเอกสารแรกในระบบ
6. ข้อมูลจากไฟล์เดิม (ลูกค้า สินค้า ประวัติ): ทีมงานช่วยย้ายให้ก่อนเริ่มใช้ สินค้าที่มีอยู่แล้วตอนเริ่มต้องมีทุนต่อหน่วย (ใช้คิดต้นทุนขาย)

## 3. ใช้งานทุกวัน

- **เข้าระบบคนละบัญชี** ออกจากระบบเมื่อเลิกใช้เครื่องที่ใช้ร่วมกัน
- **สาขา / คลัง** (อู่ที่มีหลายสาขา): เอกสารใหม่เริ่มที่คลังเริ่มต้นของแต่ละคนเสมอ ถ้าจะทำของสาขาอื่น เลือกที่ช่อง "คลัง / สาขา" ในหน้าต่างเอกสารก่อนบันทึก
- **ขาย**: ใช้ระบบขายแบบใหม่ (ใบตัดสต็อก → รับเงิน → ใบเสร็จ / ใบกำกับภาษี) รับเงินหลายวิธีในครั้งเดียวได้ เงินโอน บัตร เช็คเข้าบัญชีธนาคาร เงินสดเข้าเงินสด
- **นำเงินสดฝากธนาคาร / ถอนเงินมาใช้**: บันทึกที่เมนู 08 → เงินลงทุน / เงินสด ("ฝากเงินสดเข้าธนาคาร" "ถอนเงินจากธนาคารเป็นเงินสด") ยอดเงินสดกับธนาคารในงบจะตรงกับของจริง
- **จ่ายเงิน**: ค่าใช้จ่าย จ่ายเจ้าหนี้ จ่ายเงินเดือน ได้ใบสำคัญจ่ายทุกครั้ง หัก ณ ที่จ่ายแล้วพิมพ์ 50 ทวิ ได้
- **เอกสารที่ออกแล้วแก้ไม่ได้**: ใบกำกับภาษีที่ผิดให้ยกเลิกพร้อมเหตุผลแล้วออกใหม่ หรือใช้ใบลดหนี้ / ใบเพิ่มหนี้
- **เดือนที่ปิดงวดภาษีแล้ว** (เมนู 08 → รายงานภาษี) แก้เอกสารที่มีภาษีของเดือนนั้นไม่ได้

## 4. ทุกเดือน (เจ้าของ / คนทำบัญชีของอู่)

1. ก่อนวันที่ 7: เมนู 08 → รายงานภาษี พิมพ์ ภ.ง.ด.3 / ภ.ง.ด.53 (และ ภ.ง.ด.1 จากเงินเดือน) ยื่นแล้วกด "บันทึกนำส่ง" ของแต่ละแบบ
2. ก่อนวันที่ 15: รายงานภาษีขาย ภาษีซื้อ บรรทัด ภ.พ.30 บอกยอดที่ต้องชำระ ยื่นแล้วกด "บันทึกนำส่ง ภ.พ.30" ใส่ยอดตามแบบที่ยื่นจริง
3. ปิดงวดภาษีของเดือนเมื่อยื่นแล้ว
4. ส่งงบทดลอง (CSV) บัญชีแยกประเภท (Excel) และรายงานภาษีให้ผู้ทำบัญชี (เมนู 08)

## 5. อายุการใช้งาน

- อู่นำร่องใช้ได้ 1 ปีนับจากวันเปิด (ร้านทดลองทั่วไป 60 วัน) วันหมดอายุอยู่ที่แถบบนสุด "Expired Date … · เหลืออายุการใช้งาน N วัน"
- หมดอายุแล้วยังเข้าระบบ ดู พิมพ์ และส่งออกข้อมูลได้ แต่บันทึกอะไรใหม่ไม่ได้จนต่ออายุ
- เลิกใช้: ข้อมูลอยู่อีก 90 วันหลังวันหมดอายุ ทีมงานโทรแจ้งก่อนลบ 30 วัน ดาวน์โหลดข้อมูลเก็บไว้ได้ตลอด

## 6. เมื่อมีปัญหา

- **ลืมรหัสผ่าน**: พนักงานให้เจ้าของตั้งใหม่ในเมนูพนักงาน เจ้าของลืมรหัสให้ติดต่อทีมงาน (ทีมงานยืนยันตัวตนก่อนตั้งรหัสชั่วคราวให้)
- **ขึ้น "เชื่อมต่อ server ไม่ได้"**: ตรวจเน็ตของเครื่อง ระบบต่อใหม่เองเมื่อเน็ตกลับ งานที่ยังไม่ได้กดบันทึกยังอยู่บนหน้าจอ
- **ขึ้น "หมดเวลาการเข้าระบบ"**: มีคนเปลี่ยนรหัสผ่าน ระงับบัญชี หรือออกจากระบบที่เครื่องอื่น เข้าระบบใหม่
- **ข้อมูลหาย / บันทึกผิดทั้งชุด**: อย่าเพิ่งบันทึกอะไรเพิ่ม ติดต่อทีมงานทันที (กู้ย้อนได้ทุกนาทีภายใน 7 วัน)
- ติดต่อทีมงาน: «ช่องทาง เวลาทำการ» (LAUNCH-CHECKLIST ด่าน 2 "ใครรับเรื่องเมื่ออู่มีปัญหา")

## 7. สิ่งที่ยังไม่มีช่วงนำร่อง

- ProX โหมดออนไลน์ (เชื่อม server เครือ DriveGo) ยังใช้ไม่ได้
- แฟรนไชส์: HQ ยังไม่ออกใบกำกับภาษีให้สาขาสำหรับของที่ส่งจากคลังกลาง (J26 รอตัดสิน)
- จ่ายค่าบริการออนไลน์และต่ออายุเอง อีเมลเตือนก่อนหมดอายุ (ช่วงนำร่องทีมงานโทรแจ้ง)
