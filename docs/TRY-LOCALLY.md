# ลองระบบใหม่บนเครื่องของคุณ

เปิดระบบใหม่ (server + ฐานข้อมูล PostgreSQL) บนคอมพิวเตอร์ของคุณเอง แล้วเข้าใช้ผ่านเบราว์เซอร์
ระบบจะสร้างร้านตัวอย่างให้ 3 ร้าน (Biz, ProX, Franchise) จากข้อมูลชุด "พร้อมทดลอง" ชุดเดียวกับที่ใช้ทดสอบ

## ติดตั้งครั้งแรก

| โปรแกรม | Mac | Windows |
|---|---|---|
| Git | มากับ Xcode Command Line Tools (พิมพ์ `git` ใน Terminal แล้วกดติดตั้ง) | https://git-scm.com/download/win |
| Node.js 22 (22.18 ขึ้นไป) หรือ 24 | https://nodejs.org (เลือกรุ่น LTS) | https://nodejs.org (เลือกรุ่น LTS) |
| PostgreSQL 16 | [Postgres.app](https://postgresapp.com) หรือ `brew install postgresql@16` | ตัวติดตั้งจาก https://www.postgresql.org/download/windows/ (กดถัดไปตามค่าเริ่มต้น) |

PostgreSQL ใช้แค่ตัวโปรแกรม ไม่ต้องสร้างฐานข้อมูลหรือตั้งรหัสอะไรเอง
ทุกครั้งที่เปิด ระบบสร้างฐานข้อมูลชั่วคราวของตัวเอง และลบทิ้งเมื่อปิด

## เปิดระบบ

เปิด Terminal (Mac) หรือ PowerShell (Windows แบบปกติ ไม่ต้อง "Run as administrator") แล้วพิมพ์:

```bash
git clone -b claude/brave-goodall-0qn0qg https://github.com/Museey/drive-go.git
cd drive-go
npm install
npm run dev
```

ครั้งต่อไปใช้แค่ `cd drive-go` แล้ว `npm run dev` (ถ้ามีงานใหม่ ให้ `git pull` และ `npm install` ก่อน)
เมื่อพร้อมจะขึ้นข้อความประมาณนี้:

```
DriveGo พร้อมใช้ที่ http://127.0.0.1:3000/<รหัสร้าน>/ (ฐานข้อมูลชั่วคราว: ข้อมูลหายเมื่อปิดด้วย Ctrl+C)
  biz        http://127.0.0.1:3000/demo-biz/            dg1688 / 123456
  prox       http://127.0.0.1:3000/demo-prox/           dg1688 / 123456
  franchise  http://127.0.0.1:3000/demo-franchise/      hq / 1234 (สาขา b001 / 1234)
```

เปิดลิงก์ในเบราว์เซอร์แล้วเข้าระบบด้วยบัญชีข้างลิงก์ หน้าแรกที่เปิดครั้งแรกอาจช้าสัก 10–20 วินาที (ระบบกำลังเตรียมหน้า)

| ร้าน | ลิงก์ | บัญชี |
|---|---|---|
| Biz | http://127.0.0.1:3000/demo-biz/ | เจ้าของร้าน `dg1688` / `123456` |
| ProX | http://127.0.0.1:3000/demo-prox/ | เจ้าของร้าน `dg1688` / `123456` |
| Franchise | http://127.0.0.1:3000/demo-franchise/ | HQ `hq` / `1234`, หัวหน้าสาขา B001 `b001` / `1234`, พนักงานสาขา `staff001` / `5678` |

ปิดระบบด้วย Ctrl+C ในหน้าต่างเดิม

## สิ่งที่ควรรู้ระหว่างลอง

- **หน้าตาเหมือนระบบเดิมโดยตั้งใจ** เฟส 2 เปลี่ยนเฉพาะส่วนหลังบ้าน หน้าตาใหม่มาในเฟส 4
  จุดที่ต่างจากระบบเดิมคือจุดที่อนุมัติแล้ว: หน้าเข้าระบบไม่แสดงรหัสทดลองและไม่มีปุ่มเข้าโดยไม่กรอกรหัส,
  ตารางบัญชีแสดง `********` แทนรหัสผ่าน, HQ ของ Franchise มีข้อมูลของตัวเอง (ดู `docs/NOTES.md`)
- **ข้อมูลอยู่ใน server แล้ว** ไม่ได้อยู่ในเบราว์เซอร์ เปิดร้านเดียวกันจากอีกเบราว์เซอร์ในเครื่องเดียวกันจะเห็นข้อมูลเดียวกัน
  ถ้าจะลองหลายบัญชีพร้อมกัน ให้ใช้หน้าต่างไม่ระบุตัวตน (Incognito/Private) หรือเบราว์เซอร์อื่น
- **ร้านหนึ่งมีแพ็กเกจเดียว** ปุ่ม "เปลี่ยนแพ็กเกจ" บนแถบบนสุดจะพากลับร้านเดิม ถ้าจะดูแพ็กเกจอื่นให้เปิดลิงก์ของร้านนั้นแทน
- **รูปและไฟล์แนบ** (รูปสินค้า สลิป รูป 50 ทวิ ไฟล์คลังความรู้) เก็บแยกจากข้อมูลร้านในฐานข้อมูลชั่วคราวเดียวกัน ข้อมูลเก็บลิงก์ของไฟล์
  เมนู 10 บอกพื้นที่ไฟล์ที่ใช้จาก 2 GB (งาน 3.11) โลโก้ร้านยังอยู่ในข้อมูลเหมือนเดิม
- **ปิดแล้วข้อมูลหาย** เปิดใหม่จะได้ร้านตัวอย่างชุดเดิม (ฐานข้อมูลที่เก็บถาวรจะมีใน server ทดสอบ งาน T12)
- **ร้านตัวอย่างเป็นร้านทดลองใช้ 60 วันนับจากวันที่เปิดระบบ** (งาน 3.15) ร้านต่ออายุเองไม่ได้ ทีมงานต่ออายุด้วยคำสั่ง
  `node tools/shop-admin.mjs renew demo-biz --years 1 --db <owner database>` (ที่อยู่ owner database ขึ้นในข้อความตอนเปิดระบบ)
  ลองดูร้านหมดอายุ (อ่านอย่างเดียว) ได้ด้วย `node tools/shop-admin.mjs close demo-biz --db <owner database>` แล้วโหลดหน้าใหม่

## ถ้าเปิดไม่ได้

| ข้อความ | ทำอย่างไร |
|---|---|
| `PostgreSQL binaries not found` | ยังไม่ได้ติดตั้ง PostgreSQL หรือติดตั้งไว้ที่อื่น: บอกที่อยู่โฟลเดอร์ `bin` ของมัน เช่น Mac `PG_BIN=/Applications/Postgres.app/Contents/Versions/16/bin npm run dev`, Windows (PowerShell) `$env:PG_BIN="C:\Program Files\PostgreSQL\16\bin"; npm run dev` |
| `temporary PostgreSQL did not start` บน Windows | ปิด PowerShell แล้วเปิดใหม่แบบปกติ (ไม่ใช่ "Run as administrator") PostgreSQL ไม่ยอมทำงานด้วยสิทธิ์ผู้ดูแลเครื่อง |
| port 3000 ถูกใช้อยู่ | ใช้ port อื่น เช่น Mac `PORT=3001 npm run dev`, Windows `$env:PORT=3001; npm run dev` |
| `node` เก่าเกินไป หรือขึ้น error เรื่อง `.ts` | ติดตั้ง Node.js 22.18 ขึ้นไป หรือ 24 แล้วเปิด Terminal ใหม่ |
